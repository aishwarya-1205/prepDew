## 🔧 Getting Started

### 👇 Clone the Repository

```bash
git clone https://github.com/aishwarya-1205/prepDew.git
cd prepDew
```

### 🛠️ Install Backend Dependencies

```bash
cd backend
npm install
```

### 🏃 Run Backend

```bash
npm start
```

### 🧩 Install Frontend Dependencies

```bash
cd ../frontend
npm install
```

### 🚀 Run Frontend

```bash
npm run dev
```

You can now view the app locally at `http://localhost:3000` (or the port your framework uses).
